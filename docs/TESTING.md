# Testing strategy
Vitest checks probability boundaries, reproducible large-sample outcome distribution, memory independence, target clamping, counters, persistence including denied/corrupt storage, and duplicate shot state gating through integration/E2E. Playwright runs against production preview in desktop Chromium, mobile touch, Firefox and WebKit when installed. Exercise pointer and keyboard shots, rapid clicks, reset, modal focus/Escape, persistence, resize, visibility and sound toggle; capture browser errors and screenshots. Browser visual inspection checks sprite silhouettes, goal proportions, HUD legibility, effects and responsive layouts.

Required commands: `npm run typecheck`, `npm run lint`, `npm run test`, `npm run test:e2e`, `npm run build`. No backend or runtime services. CI installs pinned lockfile dependencies and browsers then runs the same checks. Browser screenshots and reports are generated locally and ignored; documentation records actual verified results and limits.
